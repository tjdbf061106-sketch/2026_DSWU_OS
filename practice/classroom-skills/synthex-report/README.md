# synthex-report 스킬

`synthex-report`는 특정 물질의 SynthEx 실행 결과를 근거 파일과 연결해 기록하고 보고하는 스킬입니다. 아스피린 전용이 아니며, 물질명·SMILES·실행 명령·새 출력 폴더를 제공하면 다른 분자에도 사용할 수 있습니다.

## 하는 일

1. 모델 어댑터, 설정, 소스 버전 및 출력 폴더를 점검합니다.
2. 새 실행 폴더에서 실행하고 기존 완료 결과를 덮어쓰지 않습니다.
3. `manifest.json`, 원본 모델 응답, 표준 출력 및 오류를 보존합니다.
4. 성공 시에는 입력·모델·상태·경로를, 실패 시에는 중단 단계와 오류를 근거와 함께 보고합니다.
5. 연결/설정 실패와 화학 경로 탐색 실패를 구분합니다.

## 사용 예시

```text
$synthex-report
물질: 카페인
SMILES: CN1C(=O)N(C)c2ncn(C)c2C1=O
실행 명령: [제공된 SynthEx 실행 명령]
출력 폴더: C:\\Users\\DS\\OS\\runs\\caffeine-1
```

## 주의

- API 키는 환경변수 또는 클라이언트 자격 증명 저장소에만 보관합니다.
- 모델이 제공하지 않은 경로, 수율, 조건, 실험 검증 결과를 만들지 않습니다.
- native SynthEx 어댑터가 없는데 OpenCode 같은 하네스로 직접 실행했다면, 두 결과를 같은 실행으로 표시하지 않습니다.
