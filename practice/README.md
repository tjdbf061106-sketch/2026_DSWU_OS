# 사전 수업 실습 기록

_기말 프로젝트 제출 범위 밖의 교육·실습 산출물입니다._

---

이 폴더는 오늘 수행한 SynthEx–아스피린 수업 실습을 보존합니다. 기말 프로젝트의 대상 물질, 모델 선택, 최종 보고서 또는 실제 분석 결과로 사용하지 않습니다.

- `synthex-solar-aspirin/`: OpenCode/Solar Pro 4 아스피린 직접 호출과 native SynthEx 점검 기록
- `classroom-skills/`: 수업 실습에서 만든 `synthex-report` 스킬
- `classroom-reports/`: 수업 실습 PDF 및 생성 스크립트

기말 프로젝트를 시작하면 `skill/`, `inputs/`, `runs/`, `report/` 경로에 새 자료를 독립적으로 생성합니다.
