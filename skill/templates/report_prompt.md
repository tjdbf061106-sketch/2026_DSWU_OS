# Solar Pro 4 보고서 작성 지침

입력으로 제공된 `manifest.json`, 모델별 원본 출력, 구조식 이미지, 통합 결과만 사용해 한국어 보고서를 작성한다.

## 필수 구성

1. 대상 물질의 이름, SMILES, 구조식 이미지, 선정 이유
2. 합성 경로와 단계별 반응물·생성물·출처 모델
3. 단계별 예측 조건과 출처 모델
4. 단계별 예측 수율 및 전체 경로 관점의 해석
5. 모델 결과를 통합한 합성 실험 관점의 결론
6. 모델 성능, 불확실성, 실패 사례 및 데이터 부족
7. 재현 정보: 입력, 모델/버전, 설정, 실행일, 산출물 경로

## 금지 사항

- 기록에 없는 경로, 조건, 수율, 문헌값, 구조 이미지를 만들지 않는다.
- AI 예측을 실험 검증 결과처럼 쓰지 않는다.
- 실패한 단계를 성공한 것처럼 요약하지 않는다.
- 20페이지를 초과하지 않는다.

## 작성 규칙

- 구조식 이미지와 합성 경로 도식을 본문에서 읽기 쉬운 위치에 둔다.
- 예측값, 문헌 측정값, 미확인 정보를 표와 문장으로 구분한다.
- 누락된 분야는 `미실행` 또는 `실패`와 근거 파일 경로를 표시한다.
