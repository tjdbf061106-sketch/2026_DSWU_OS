# AI 신약 유기합성 기말 프로젝트 Skill

## 입력

입력 JSON에서 `target_id`, 물질명, 유효한 SMILES, 선정 이유를 확인한다. 실행 전 `config/project.local.yaml`의 모델명, 버전, 명령, 자산 경로, 실행 한도를 확인한다. API 키는 환경변수 또는 OpenCode 자격 증명에만 두고 어떤 산출물에도 기록하지 않는다.

## 실행 순서

1. `scripts/prepare_run.py`로 새 `runs/<run-id>/` 폴더와 `manifest.json`을 만든다.
2. 선택된 경로 모델을 실행하고 원본 출력·표준 출력·표준 오류를 저장한다.
3. 경로의 각 유효 반응 단계에 선택된 조건 모델을 실행하고 단계별 원본 출력을 저장한다.
4. 같은 단계에 선택된 수율 모델을 실행하고 예측값·단위·모델 출력을 저장한다.
5. 구조식 이미지와 경로 도식을 생성한다. 생성 실패 시 오류와 누락 파일을 기록한다.
6. 모든 근거 파일을 읽은 뒤 Solar Pro 4로만 최종 보고서를 작성한다. 보고서는 최대 20페이지 PDF 또는 DOCX로 `report/`에 저장한다.

## 사실성 규칙

- 실제 실행 출력, 문헌 측정값, 예시, 미실행 항목을 분명히 구분한다.
- 경로·조건·수율 모델 중 하나가 실패하면 실패 단계와 오류를 보고하고 없는 결과를 채우지 않는다.
- 보고서 본문을 사람이 수동으로 고치지 않는다. 문체나 근거 연결을 개선하려면 이 Skill 또는 `templates/report_prompt.md`를 고친 뒤 Solar Pro 4로 다시 생성한다.
- 모델·가중치·자산이 아직 확정되지 않으면 실행을 중단하고 필요한 설정을 보고한다.

## 출력

각 실행은 입력 사본, `manifest.json`, 모델별 원본 응답, stdout/stderr, 구조 이미지, 통합 결과 JSON, Solar Pro 4 보고서를 포함해야 한다. 보고서에는 대상 물질·선정 이유·경로·조건·수율·통합 해석·한계·실패 사례·구조식 이미지를 포함한다.
