# 제출용 Skill

_Solar Pro 4가 읽고 최종 보고서 작성 과정을 재현할 수 있도록 구성하는 제출용 폴더입니다._

---

## 📦 구성

| 경로 | 역할 |
|---|---|
| `SKILL.md` | 입력 검증부터 보고서 생성까지의 핵심 지침 |
| `scripts/` | 실행 폴더와 매니페스트를 준비하는 보조 코드 |
| `references/` | 모델별 실제 선택·설치·한계 근거 |
| `templates/` | Solar Pro 4에 전달할 보고서 작성 템플릿 |

현재는 모델 선택 전 뼈대입니다. `SKILL.md`의 `미정` 항목은 실행 전에 실제 설정으로 채워야 하며, 모델이 아직 실행되지 않았다면 결과를 만들지 않습니다.
