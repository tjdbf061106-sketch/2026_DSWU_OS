# 기말 프로젝트 구현 계획

_초기 계획 — 실제 모델 및 대상 물질 확정 전 상태_

---

## 🎯 최소 재현 가능 목표

동일한 입력 JSON과 로컬 설정을 사용하면, Skill이 경로·조건·수율 모델의 결과 또는 실패를 `runs/<run-id>/`에 보존하고 Solar Pro 4가 최종 보고서를 생성하는 상태를 목표로 합니다.

## ⚙️ 필요 환경

| 구분 | 현재 준비 | 최종 확정 시 채울 내용 |
|---|---|---|
| Python | `requirements.txt`에 공통 패키지 명시 | Python 버전과 잠금 파일 |
| 경로 모델 | 미선정 | 모델명, 버전, 자산, 실행 명령 |
| 조건 모델 | 미선정 | 모델명, 버전, 자산, 실행 명령 |
| 수율 모델 | 미선정 | 모델명, 학습 가중치, 입력 규격 |
| 보고서 모델 | Solar Pro 4 필수 | OpenCode 또는 선택 하네스의 실제 명령 |
| 구조식 이미지 | RDKit 사용 예정 | 실제 이미지 생성 스크립트와 검증 결과 |

## 📋 미확정 사항

- [ ] 최종 대상 물질 및 선정 이유
- [ ] 경로 예측 모델 조합
- [ ] 조건 예측 모델 조합
- [ ] 수율 예측 모델과 가중치·학습 데이터
- [ ] 외부 자산의 라이선스, 다운로드 방법, SHA-256
- [ ] 실행 예산과 재시도 한도
- [ ] 최종 보고서 형식(PDF 또는 DOCX)
- [ ] 선택 추가 분석(하네스 비교, MOPAC, EPI Suite, 3D 분석)

## ✅ 완료 기준

교수 요구사항의 체크리스트를 루트 `README.md`에서 추적합니다. 각 항목은 실제 파일과 실행 로그로 확인할 수 있을 때만 완료로 표시합니다.
